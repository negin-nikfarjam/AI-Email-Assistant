# AI Email Assistant

A customer support email analysis app built with Python and Streamlit.

## Features
- Email classification
- Priority detection
- Rule-based summaries
- Suggested customer replies
- Free Demo Mode
- Optional OpenAI API integration
- JSON and TXT downloads

## Installation
Install dependencies: pip install -r requirements.txt

Run: streamlit run app.py

## Demo Mode
Uses keyword rules and response templates, not AI.

## AI Mode
Requires an OpenAI API key and available credits. Full API testing is pending.
